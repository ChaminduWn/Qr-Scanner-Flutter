WN QR Scanner & Generator is a Flutter-based mobile application that allows users to scan and generate QR codes with ease. The app supports various types of QR codes, including text, URLs, and contact information. It also provides features like sharing QR codes, saving scanned contact information, and opening URLs directly from the app.

## Features

- **QR Code Scanning**: Scan QR codes with your device's camera. The app can detect text, URLs, and contact information.
- **QR Code Generation**: Generate QR codes for text, URLs, and contact information.
- **Share QR Codes**: Share generated QR codes as images via other apps.
- **Save Contacts**: Save scanned contact information directly to your device's contact list.
- **Open URLs**: Open scanned URLs directly in your default web browser.
- **Customizable UI**: A sleek, dark-themed UI with neon accents for a futuristic look.

## Dependencies

1. **flutter: The core framework for building the app.**
2. **google_fonts: For custom fonts.**
3. **qr_flutter: For generating QR codes.**
4. **mobile_scanner: For scanning QR codes.**
5. **flutter_contacts: For handling contact information.**
6. **share_plus: For sharing QR codes.**
7. **url_launcher: For opening URLs.**
8. **screenshot: For capturing QR code images.**
9. **path_provider: For accessing the device's file system.**
